# Personal-Song-URL-Library
A private MP3 song library for obtaining relevant URLs — please note it is for personal use only.  
一个私人的mp3歌曲库用于获取相关url，请注意是自用的


Hi there 👋  
As the title says, this is a personal MP3 library for turning songs into browser-playable URLs.  
If you stumbled upon this repo while searching for certain keywords, I'm truly sorry it's probably not helpful. My sincere apologies for any inconvenience.  
你好，  
正如标题所写，这是一个自用的mp3歌曲库，用于转化为浏览器可直接在线播放的url。如果你正在搜寻相关关键词注意到了这个库，我深表歉意可能这个库没有什么帮助，如有打扰我再次深表道歉。  
**使用流程**  
1.mp3的处理 
  - 以防又莫名其妙的问题，建议使用音频处理工具先处理一遍  
    *相关数据如下*
  >编码模式：恒定码率 (CBR)

  >码率：128 kbps 或 192 kbps

  >采样率：44100 Hz （绝对不能选 48000 Hz 或其它）

  >声道：立体声 (Stereo)

  >文件名中的空格替换为“-”或删去


2.上传与获取mp3直链  

  - 获得库的编辑权限或克隆到自己账户下，上传已经处理好的mp3文件，复制mp3文件名
  - 在库的设置==>页面菜单下可找到链接(https://sgartcn.github.io/Personal-Song-URL-Library/) ，如有变动请自行在设置里页面菜单下查看
  - 把mp3文件名复制在连接末尾(https://sgartcn.github.io/Personal-Song-URL-Library/[mp3文件名]) ，此链接就是mp3直链


如果流程没问题，你已经获得了mp3直链，尽情享受音乐吧 ;)  
**若出现问题请在评论区求助，我会尽我所能帮助您🍵**
